## 5. 开场动画规格（只在首页首屏）

- 效果：首屏每个区块先显示**蓝色虚线框 + 斜线填充 + 左上角等宽标签**（LABEL / TITLE · 1200 / COPY 01 / META / PLATE 01），随后线框淡出、真实内容淡入并上移 8px。
- 时长：线框停留约 500ms，内容过渡 500ms，区块依次延迟 0 / 60 / 120 / 180ms。总时长 ≤ 1.2s。
- 不挡路：真实文字从首帧就在 DOM 中；动画期间可以滚动、可以点击；没有独立加载页，没有「点击进入」。
- 只播一次：用 `sessionStorage` 记录 `introPlayed`，同一会话刷新或从案例页返回不再播放。读写必须 try/catch，失败时按「已播放」处理。
- `prefers-reduced-motion: reduce` 时直接显示成品（CSS 和 JS 双重兜底）。
- 案例页不要任何开场或加载动画。
- 颜色：线框用 `--accent`，背景始终是 `--bg`，不出现整屏蓝底。

### 实现方式（参考 imdaryl.com 的做法）
- **不用动画库。** 参考站是 React + 纯 CSS `@keyframes`，没有 GSAP、Framer Motion 或 Lottie 运行时。本站同样只用 CSS 实现开场，GSAP 如果其他地方不用就整体移除。
- **线框层**：一个绝对定位的覆盖层，用 JS 读取首屏各区块的 `getBoundingClientRect()`，在对应位置画出虚线框和标签（区块类型按元素判断：`h1` → TITLE，段落 → COPY，按钮/链接 → CTA，图片 → PLATE）。窗口尺寸变化时重新测量。
- **出现方式**：用 `clip-path: inset()` 做「画出来」的效果，不用 `width` 动画：
  - 横线 / 尺寸线：`clip-path: inset(-8px 100% -8px 0)` → `inset(-8px 0 -8px 0)`
  - 竖线：`clip-path: inset(0 0 100% 0)` → `inset(0 0 0 0)`
  - 线框块：从左向右展开，同时 `opacity` 0.5 → 1
- **依次出现**：每个区块设置 CSS 变量 `--i`（0、1、2…），延迟写成 `animation-delay: calc(var(--i) * 60ms)`，不要在 JS 里逐个计时。
- **缓动**：在 `:root` 定义两个缓动变量，例如 `--ease-draw: cubic-bezier(.65, 0, .35, 1)`（画线）和 `--ease-settle: cubic-bezier(.2, .8, .2, 1)`（内容落定），全站统一引用。
- **时长**：参考站完整开场约 2.6 秒，本站压缩到 1.2 秒以内：网格 0–200ms、线框 100–500ms、标签 300–600ms、线框淡出 + 内容淡入 500–1100ms。
- 动画结束后移除覆盖层（`animationend` 后卸载），不留在 DOM 里。
