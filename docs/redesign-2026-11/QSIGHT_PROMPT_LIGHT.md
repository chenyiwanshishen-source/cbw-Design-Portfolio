# 修改：Qsight 的 Prompt 部分再减一轮，只留面试官会追问的地方

接着 `QSIGHT_PROMPT_TASK.md` 的结果继续，在分支 `redesign/qsight-prompt` 上提交，不开新分支。本文件和上一份冲突的地方，以本文件为准。只改 Prompt 这一块（`qsight-04` 里"设计方案"之后到"用编译器写各章的 Prompt"），其他章节不动。

## 为什么再减

这块的作用是让面试官停下来问一句"为什么这样做"，不是把 Prompt 讲完。能被追问的只有四个点：正反样例、先用弱模型验证、不做控制台、编译器。其余内容放到面试里当面讲。

## 1. 删掉重复的四行表格

"设计方案"下面已经有彩色的四个阶段卡片，后面又跟着一个内容几乎一样的四行表（任务定义 / 工具编排 / 质量门禁 / 容错兜底）。

- 删掉这个表（对应的 `layers` 块）。
- 阶段名统一用彩色卡片上的名字：任务定义、工具编排、质量检查、异常处理。
- 卡片上的副标题改成下面这样：

| 阶段 | 副标题 |
|---|---|
| 任务定义 | 目标、身份、成功标准 |
| 工具编排 | 要什么输入，按什么顺序调用哪些工具 |
| 质量检查 | 约束边界、输出格式、数据依据 |
| 异常处理 | 重试、兜底，交付前的自检清单 |

## 2. 把"三个问题"和"四个阶段"连起来

页面上方已经有三张问题卡（生成内容严重跑偏 / 跳过该用的工具 / AI 编造数据），下方是四个阶段卡，现在两块是断开的。

在阶段卡上加小标签，写它挡住哪个问题（标签文字逐字使用）：

- 任务定义：挡住"内容跑偏"
- 工具编排：挡住"跳过工具"
- 质量检查：挡住"内容跑偏""编造数据"
- 异常处理：挡住"编造数据"

标签用 `tokens.css` 里已有的小字号和浅色，每个标签不超过一行。如果能加问题卡到阶段卡之间的细线就加；做不到干净，就只加标签，不要硬画连线。

## 3. 正反样例改成两张并排的小报告卡

替换"一个章节的 Prompt 里写了什么"里现有的 `columns`（正例 / 反例两段文字）。新增一个只服务这一处的组件，放在 `src/app/cases/components/`，名字例如 `PromptExample`；颜色、字号只用 token，不新增依赖，不加动画。

保留这一节开头的 `paragraph`（含【待填：为什么这样要求……】）和结尾那段 `paragraph`（用户要求永远大于系统提示词、自检清单一共 6 项）。

**左卡：标题"正例"，右上角小标签"通过"**

```
一、获得融资、业务拓展、新品发布类
（1）星火科技 宣布完成2亿元B轮融资，资金将用于AI产品研发及团队扩充。 [来源]
（2）蓝天智造 正式发布"天工3.0"智能机械臂，作业精度提升40%。 [来源]
二、榜单类
（1）云端网络 入选2025年全球云计算企业百强榜单第15位。 [来源]
```

**右卡：标题"反例"，右上角小标签"违规"**

```
一、获得融资、业务拓展、新品发布类
本月呈现上升趋势，共有2家重点企业获得融资。      ← 标注"违规：总结"
（1）星火科技 宣布完成2亿元B轮融资。 [来源]
| 企业名称 | 融资金额 |                           ← 标注"违规：表格"
| 星火科技 | 2亿 |
```

- 两处违规的行用一条细线或浅色底标出来，标注文字放在行右侧；375 宽度下标注移到该行下方。
- 卡片下方一行小字：`示例数据，企业为虚构。`
- 两张卡下面再放一条"交付前自检"：只显示两项，其余折叠成"另外 4 项"：
  - 是否已全局去重，确保信源唯一
  - 是否彻底排除了任何形式的总结、图表和表格
- 375 宽度下两张卡上下排列，不横向滚动。
